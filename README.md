# Projeto de Projeção de Investimentos em FIIs

## Descrição
Projeto desenvolvido para simular cenários de investimentos em Fundos Imobiliários, com foco em organização, análise e projeção de resultados.

## Tecnologias
- Excel Avançado
- Planilha automatizada
- Lógica financeira
- Visualização de dados

## Objetivo
Auxiliar na análise de cenários de investimento, permitindo visualizar diferentes possibilidades de retorno e distribuição de ativos.

## Funcionalidades
- Simulação de cenários
- Cálculo de projeções
- Organização de dados financeiros
- Análise comparativa de investimentos em FIIs

## Como usar
1. Baixe a planilha
2. Ajuste os valores de entrada
3. Analise os cenários e resultados

## Status
Em desenvolvimento

## Observações
Projeto voltado para prática de análise financeira, organização de dados e estudo de projeções em investimentos.
